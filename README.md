# ShopSphere — E-commerce REST API

ShopSphere is a backend e-commerce application built using Java and Spring Boot. It is designed to demonstrate REST API development, relational database management, layered architecture, and backend security.

## Tech Stack

* Java 17
* Spring Boot 3
* Maven
* Spring Data JPA / Hibernate
* MySQL
* Bean Validation
* Spring Security and JWT — if implemented

## Features

* RESTful API architecture
* Product and category management
* Cart and order management
* Request validation and exception handling
* Database persistence using Spring Data JPA
* Authentication and role-based authorization — if implemented

## Getting Started

### Prerequisites

* Java 17
* MySQL
* Git

### Setup

1. Clone the repository.
2. Create a MySQL database named `shopsphere`.
3. Configure the database URL, username, and password using your local application configuration or environment variables.
4. Run the application:

```bash
./mvnw spring-boot:run
```

### Tests

Run the test suite:

```bash
./mvnw clean test
```
